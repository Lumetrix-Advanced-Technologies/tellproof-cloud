1. Connect an evidence agent

The agent runs next to your product, drops all message content, and sends only signed hourly aggregates. Create a one-time token, then run the agent with it.

{{with .Data.NewToken}}

Enrolment token (shown once, valid for 24 hours, one use):

{{.}}

Enrol the agent and run it:

export PLUMBLINE_SERVER={{$.Data.APIBase}}
export PLUMBLINE_ENROL_TOKEN={{.}}
export PLUMBLINE_SALT_SECRET="$(openssl rand -hex 32)"   # keep it: it lets you disclose a trace later
plumbline-agent enrol --config agent.json
plumbline-agent run --config agent.json

Then add one line to your app (Python pip install plumbline, or Node npm install @plumbline/sdk):

import plumbline; plumbline.init()          # Python
import * as plumbline from '@plumbline/sdk'; plumbline.init();   // Node
{{end}}
