1. Connect an evidence agent

The agent runs next to your product, drops all message content, and sends only signed hourly aggregates. Create a one-time token, then run the agent with it.

{{with .Data.NewToken}}

Enrolment token (shown once, valid for 24 hours, one use):

{{.}}

Run the agent on the machine or cluster next to your app (Docker):

docker run -d --name plumbline-agent --restart unless-stopped -p 127.0.0.1:4318:4318 -v plumbline-agent:/data -e PLUMBLINE_SERVER={{$.Data.APIBase}} ghcr.io/lumetrix-advanced-technologies/plumbline-agent:latest connect {{.}}

Or with the downloaded binary: PLUMBLINE_SERVER={{$.Data.APIBase}} plumbline-agent connect {{.}}

Add one line to your app (pip install plumbline or npm install @plumbline/sdk):

import plumbline; plumbline.init()                              # Python
import * as plumbline from '@plumbline/sdk'; plumbline.init();   // Node.js

The agent's first batch appears below about a minute after your app's first model call. Keep the plumbline-agent volume: it holds the agent's key and the salt that lets you disclose a trace later.
