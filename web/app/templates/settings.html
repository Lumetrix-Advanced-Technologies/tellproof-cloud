Packs are signed by Witnessmark's key. Reviewers verify them against /.well-known/jwks.json, and every pack issued each day is listed in the public daily checkpoint.

Vanta

{{with .Data.Vanta}}

Each hour Witnessmark sends Vanta one resource per evidence objective of each AI system, from its latest pack (status, pack digest and a verify link), and uploads new packs to a Vanta document. Nothing else is sent.

Set up Vanta first
  1. In Vanta's developer console, create an application for a private integration. Note its client ID and secret.
  2. In the application's Resources tab, add a custom resource named AI assurance objective with these properties: objectiveId, objective, system, status, packId, packDigest, periodStart, periodEnd, verifyUrl (all strings), passing (boolean) and lastEvaluated (timestamp). Copy its resource ID.
  3. Optional: create a document in Vanta for the signed packs and copy its ID.
  4. Paste them below. In Vanta, a custom test with the rule passing equals true then fails when an objective does.
